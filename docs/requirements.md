# Requirements

## Functional Requirements

1. User must upload resume (PDF)
2. User must enter job description text
3. System must extract skills from resume
4. System must conduct voice-based Q&A
5. System must generate adaptive follow-ups
6. System must evaluate answers via rubric
7. System must generate structured report
8. User must download report as PDF

## Non-Functional Requirements

- Response latency < 3 seconds
- Interview duration: 15–25 mins
- Audio transcription accuracy > 90%
- Secure resume storage
- Session-based memory

## Constraints

- Budget-conscious LLM usage
- No real-time video processing
- Scalable backend structure
