# Product Requirements Document (PRD)
## AI Voice Mock Interview – MVP

## 1. Problem
Students lack access to realistic mock interviews.
Human mock interviews are expensive, inconsistent, and not scalable.

## 2. Solution
An AI-powered 1:1 voice mock interview platform that:
- Takes resume + job description
- Conducts adaptive voice interview
- Provides structured evaluation report
- Tracks improvement across sessions

## 3. Target Users
- Final year students
- Freshers preparing for placements
- Tier-2/3 college students

## 4. Core MVP Features
- Resume upload (PDF)
- Job description input
- Voice-based interview (10–15 questions)
- Adaptive follow-ups
- Structured scoring rubric
- Downloadable PDF report

## 5. Out of Scope (MVP)
- Real-time emotion detection
- Multi-language support
- Company-specific premium packs
- Live video avatars

## 6. Success Metrics
- Interview completion rate
- Report downloads
- User returning for 2nd session
